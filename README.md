## About this repository (このレポジトリの使い方)

### Providing comments to drafts (作成中の日本語の文案へのコメント)

As for now, every drafts are written only in Japanese, and Japanese Language Task Force is planning to formally start development of JLreq-d document once members reached mutual consensus on its content, such as which item to be included and not to be included, and which direction to be taken for each component. 
Discussions are mostly held in meetings and some are also in [GitHub Discussions](https://github.com/w3c/jlreq-d/discussions), but please use [GitHub Issues](https://github.com/w3c/jlreq-d/issues) to provide comments. 

現段階では日本語文章でのみ文案が作成されており、日本語組版タスクフォースではメンバー間でJLreq-dに記述する内容について合意が取れた時点で、正式に文章の作成を開始する予定です。これにはJLreq-dに何を記述して何を記述しないのか、もしくは各組版要素に対してどの方向性で記述するのかが含まれます。
文案の議論は主に会議内で行われていますが、いくつかは[GitHub Discussions](https://github.com/w3c/jlreq-d/discussions)でも行われています。しかしながら、文案へのコメントをいただく際には[GitHub Issues](https://github.com/w3c/jlreq-d/issues)へあげていただくようにお願いします。
