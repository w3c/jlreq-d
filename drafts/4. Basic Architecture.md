# 4. 日本語組版の基本アーキテクチャ(Foundational Architecture of Japanese Line Layout)
> 詳細ではなくアーキテクチャの話。英語ベースの組版を知っている人に、それとは異なるアーキテクチャであることを印象付ける。また、ではラテンベースラインの仕組みの中にどのように実装するか、 を説明する。

## 4.1 日本語組版の基本アーキテクチャ
> ここではまず和字の基本を説明して、和字の組版は欧文ベースラインとは異なるシステムであることを説明。和字の組版の基本をわかってもらうためにある。本格的に説明すると言うよりも、ボディによる組み方のアーキテクチャ（中心揃え＋ベタ）を簡単に説明する。ベースラインという概念はないよ。サイズの異なる文字の配列について、中央揃えが基本だと説明。

> ラテン組版と日本語組版の違いをここでカバー。重要なポイント。
> 1. ボディが基本
> 2. 基本的にベタ組み（X方向）
> 3. どこでぶった斬っても良い（X方向）
> 4. 行内は中央揃えが緩い基本。88%を追認してもいい？？（Y方向）
> 5. 行間が違う（行と行との関係Y方向）

日本語の文字の設計は、統一したサイズの、多くの場合、正方形の枠、つまりボディがあって、その中で字面をデザインしている。ラテン文字のように、ベースライン、ミーンライン、アセント、ディセント、などの構造がない。（活字のイラスト、デジタル文字のイラスト）

多くの日本語フォントでは、ボディは正方形であり、同じグリフを縦組、横組両方で使用する。よって字面の設計にあたっては、縦組、横組両方の配置において文字間や上下左右の位置が揃って見えるようにデザインされている。ボディが長方形である日本語フォントもあり、縦長のものはもっぱら横組、横長のものはもっぱら縦組に使われる。

字詰め方向（文字を並べてゆく方向）については、ボディを密着させて配置していく。行を分割する場合、ラテンスクリプトでは単語間で行うが、日本語においては原則としてどこの文字間でも分割が可能である。

この基本のままでレイアウトできるのが最も理想的だが、下のような処理に対処するため、字間の調整の必要が出てくる。
1. 連続した約物の処理
2. 例外的に分割できない文字の処理
3. ラテン文字などプロポーショナルな文字の挿入
4. ジャスティフィケーションに伴う行の調整
5. 空け組、詰め組の処理（トラッキングの処理）
この処理の巧拙が日本語組版処理の読みやすさ、美しさに大きく影響する。この点について5章で詳説する。

日本語では、ボディの行送り方向の中心を通る線を基準にして配列する。また、横組では、目的により下端または上端で揃える場合もり、その行の主となるフォントサイズにおけるボディの下端や上端を通るラインも必要となる。配列の際に行送り方向の揃える基準となる線をベースラインと呼ぶが、和文組版においては中心、下端、上端、と合計三つのベースラインが存在する。同様に縦組は、中心、右端、左端の三つのベースラインが存在する。

また、マージンを指定された領域の中に行を配置する場合にも、ボディの端が基準となる。よって最初の行の位置を決めるために横組ではボディの上端の位置が必要となる。末尾についても同様である。

宿題きだ：9-29

日本語の行間は一般的に英語よりも広く取る必要がある。これは、殆どの文字がボディいっぱいにデザインされているからである。英語においては、多くの小文字の字面がベースラインとミーンラインの間に収まっているので、ミーンラインより上の部分、およびベースラインより下の部分が実質的に空間となっている。このために、日本語よりも行間を狭くできる。
