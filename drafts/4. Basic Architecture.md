# 4. 日本語組版の基本アーキテクチャ(Foundational Architecture of Japanese Line Layout)
> 詳細ではなくアーキテクチャの話。英語ベースの組版を知っている人に、それとは異なるアーキテクチャであることを印象付ける。また、ではラテンベースラインの仕組みの中にどのように実装するか、 を説明する。

## 4.1 日本語組版の基本アーキテクチャ
> ここではまず和字の基本を説明して、和字の組版は欧文ベースラインとは異なるシステムであることを説明。和字の組版の基本をわかってもらうためにある。本格的に説明すると言うよりも、ボディによる組み方のアーキテクチャ（中心揃え＋ベタ）を簡単に説明する。ベースラインという概念はないよ。サイズの異なる文字の配列について、中央揃えが基本だと説明。

> ラテン組版と日本語組版の違いをここでカバー。重要なポイント。
> 1. ボディが基本
> 2. 基本的にベタ組み（X方向）
> 3. どこでぶった斬っても良い（X方向）
> 4. 行内は中央揃えが緩い基本。88%を追認してもいい？？（Y方向）
> 5. 行間が違う（行と行との関係Y方向）

日本語の文字（和字。言葉の定義が必要）は一般的に、統一したサイズの正方形の枠、ボディ、を持ち、その枠内に中心を基準としてデザインされている。横組の場合でも、縦組の場合でも、このボディを中心揃えで隙間なく並べてゆくのが日本語組版の基礎である。そのため、ボディの中には設計された文字間の空間が組み込まれている（図）。

この、ボディを中心揃えで隙間なく並べてゆく方法は、ラテンアルファベットにおける、ベースラインを基準として、その上に文字を並べてゆく方法と対照的である。子供が文字を学ぶ練習帳にこの違いがよく現れている（イメージを二つ）。図でわかるように、日本語の練習帳では、矩形のボディの中に十字線が描かれており、それを中心として、また前後の文字との間隔が適切となるように文字を書いてゆく。

異なる大きさの文字を並べる際にも、この中心線で揃えるのが基本である。しかし、目的により横組の場合下端または上端、縦組の場合左端や右端で揃える場合もあり、その場合、その行の基準となるフォント、サイズにおけるボディの上下端、左右端を通るラインが必要となる。すなわち、和文組版においては合計三つのベースラインが存在することになる。

マージンを指定された領域の中に行を配置する場合にも、ボディの端が基準となる。よって最初の行の位置を決めるために横組ではボディの上端の位置が必要となる。末尾についても同様である。

日本語の行間は一般的に英語よりも広く取る必要がある。これは、殆どの文字がボディいっぱいにデザインされているからである。英語においては、多くの小文字の字面がベースラインとミーンラインの間に収まっているので、ミーンラインより上の部分、およびベースラインより下の部分が実質的に空間となっている。このために、日本語よりも行間を狭くできる（図示）。

上に述べたように一般的な日本語フォントでは、ボディが正方形であり、同じグリフを縦組、横組両方で使用する。正方形であることの利点は、これによって文字が縦組、横組両方に使いやすいことである。ボディが長方形である日本語フォントもあり、縦長のものはもっぱら横組、横長のものはもっぱら縦組でスペースを節約したい際や、短い行長に多くの文字を入れる場合に、文字サイズを大きく取りたい場合にに使われることが多い。またタイトルなどの文字列幅を調節するなどの目的で、横組でも横長のものを用いることもある。


さて、この基本のままでレイアウトできるのが最も理想的だが、下のような処理に対処するため、字間の調整の必要が出てくる。

1. 連続した約物の処理
2. 例外的に分割できない文字の処理
3. ラテン文字などプロポーショナルな文字の挿入
4. ジャスティフィケーションに伴う行の調整
5. 空け組、詰め組の処理（トラッキングの処理）

この処理の巧拙が日本語組版処理の読みやすさ、美しさに大きく影響する。この点について5章で詳説する。
