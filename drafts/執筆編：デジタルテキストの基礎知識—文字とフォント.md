# 2 日本語の文字

デジタルテキストは、文字とスタイル、の2つのものからできている。文字は書き手が並べたものがそのまま保たれ、変化しない。スタイルは一般的には書き手が与えるが、読み手の環境に応じて変わる。

このうち基本となるものは文字であり、文字が表示される字の大まかな形、行の折り返し位置、文字と文字の間隔など表示の基本を決定する。また、文字は意味を持ち、検索、AIによる解釈、機械翻訳、読み上げといった操作の対象となる。よって正しい文字を用いることがデジタルテキストの作成にとって最も重要である。

また、文字が決めるのは字の大まかな形までで、そこから先の具体的な字形はフォントが決める。フォントはスタイルの一つだが、選び方を誤ると意図しない字形で表示される。字形の違いは書体の個性にとどまらず、日本語として適切でない字形になることがある。よって、正しいフォントを使うことも重要である。

この章と次の章で、日本語書き言葉の特徴、文字の使い方、そしてフォントの選び方について述べる。

## 2.1 日本語書き言葉の特徴
> この節はデジタルデバイス上の書き言葉にフォーカスした日本語の特徴の簡潔なサマリー。日本語にネイティブでない人が対象だが、日本人でも発見があるかもしれない。以降の章に役に立つことを主眼に。言葉は簡潔に。例を豊富に使ってイメージで理解させる。

### 多様な文字種の使用
現代の日本語は、表意文字である漢字と、表音文字であるひらがながその骨格をなしており、典型的には漢字の列とひらがなの列の繰り返しに見える。この表記方法を「漢字仮名交じり文」と呼ぶ。漢字部分は意味を表し、ひらがな部分は、主に語と語をつなぐ助詞を表し、また送り仮名として語の活用を示す。漢字は比較的複雑で四角く見え、ひらがなは比較的単純で曲線が多い。

日本語には空白など語の区切りを示す文字はないが、この漢字とひらがなの濃度、形や大きさの差がリズムを作り、これが非明示的に語句のまとまり〈the grouping of phrases〉を示すので、明示的に語句を区切る文字がなくても語句のまとまりをおおまかに認識できる。

##### 図：漢字仮名交じり文
```
>日本語が漢字とひらがなの繰り返しに見えることを示す例。どこが漢字か、ひらがなかが示してあり、またそれぞれの語に品詞と訳がある。Claudeによるとhtmlで可能だとのこと。rubyとinterlinear glossingを使う。縦書き用には実装を変える必要あり。
```

明示的に語を区切る文字がないという点が、空白などによって明示的に語が区切られている言語との大きな違いである。例えば英語の空白は語の区切りを示すだけでなく、行を組むときに伸び縮みして行長を調整する役割も担っている。日本語のテキストにはこの可変長の空白のないことが、レイアウトの方法に大きな影響を与える。

また、このため語の区切りが明確でなく、そのため語の定義自体が必ずしも明確でない。例えば「日本語学習者」が一語なのか、「日本語」「学習」「者」の三語なのかが定まらない。英語から空白を取り除いた場合に、busstopがbus+stopの2語であるのか、busstopと1語なのか曖昧となることに似ている。

上記の漢字やひらがな以外に、各々独自の役割を持つカタカナ、ラテン文字、アラビア数字、約物や記号、絵文字なども使われる。次章で詳細を説明する。

##### 図：様々な種類の文字の含まれる日本語
```
>カタカナやラテン文字、数字、約物、記号、絵文字も含まれた日本語の例。どれがどの文字種かの説明付き。若者の会話っぽい例文だと絵文字は含めやすいか。多様な言語の文字を目的外使用した字で作った顔文字も良い例か？"✿·͜·ᰔ!!"みたいな例。日本語か？と言われると疑問だが、絵文字を含めるなら、これを除外する理由もあまりない。どうしましょ。生きた例として良いかも。
```


### 日本語の二重構造と読み仮名の必要性
後に述べるように、ひらがなとカタカナは日本語の音を表す文字であり、まとめて仮名と呼ばれる。漢字で書かれる部分もすべて仮名で書くことができる。漢字で書かれた部分の音を仮名で書き表したものを、その「読み」と呼ぶ。

日本語では、書かれたものから読みが一意に決まらない。多くの漢字が複数の読みを持っており、また熟語〈kanji compound〉や固有名詞では読みが個々の漢字の読みから乖離している場合がある。多くの場合、読みはコンテキストから類推できるが、固有名詞の例のように真に曖昧な場合もある。

##### 図：読みを容易に一通りに類推できる例
```
「漢字（かんじ）」漢字の読みから組み立てられる例
「紫陽花（あじさい）」熟字訓
>難しい漢字の例。知っている人なら一位に定まるが、多くの人は知らない。つまり類推の難易度が色々ある
```

##### 図：読みが真に曖昧な例
```
「私の名前は菅野です」 すがのなのか、かんのなのか、不明。
My name is Kanno/Sugano.
「私は日本橋にいます」 にほんばしなのか、にっぽんばし、なのか不明。
I am at Nippon-bashi / Nihon-bashi.
```

このため、日本語では、漢字部分をどのように読むかを示すために、読みを傍らに小さく書き添える振り仮名が発達した。振り仮名を印刷で扱う仕組みをルビといい、デジタルテキストでもこの名で呼ばれる。また、名前や住所を記入するフォームには「読み」の欄が設けられる。また、2025年に戸籍法が改正され、氏名の振り仮名が戸籍の記載事項に追加された。これらの例が示すように、日本語では、書かれたものとその読みが二重構造を作っている。

##### 図：前の2例をルビ付きで
```
> 難しい例にルビを振る
「私の名前は菅野（すがの）です」 My name is Sugano.
「私は日本橋（にほんばし）にいます」 I am at Nihon-bashi.
```

##### 図：名前と住所のフォームの例
```
>曖昧な名前と地名。先ほどの名前：菅野と住所：日本橋。
```

##### side note: 英語で書き言葉と読みの対応が曖昧になる例
```
英語でも書き言葉と読みの対応が曖昧になる例は存在するが例外的である。日本語ではそれが常態であるため、振り仮名や読みの欄などの仕組みが発達した。
e.g. I saw her bow. (/boʊ/ 弓 or /baʊ/ お辞儀する)
```

### 表記の揺れ
上記の逆方向、即ち、読みをどう書き表すかも複数の書き方があって一意に決まらない場合がある。送り仮名の付け方が複数認められているもの（「引っ越し」「引越し」「引越」）、同じ単語に複数の書き方がある場合（「卵」「玉子」）、漢字で書くか仮名で書くか（「たまご」「卵」）などがある。どれも誤りではなく、どれを選ぶかは書き手の選択になる。

##### site note: 漢字仮名交じり文とルビの歴史
```
現代の日本語表記は、二つの方向の技術から来ている。日本語を漢字で書くための技術と、古代中国語で書かれた文を日本語として読むための技術である。
前者からは、語の主要な部分を漢字で書き、助詞・活用語尾を表音的な文字で書き添える方式が現れた。これが宣命書きであり、漢字仮名交じり文の源流のひとつとされる。
後者からは、注記の技術が発達した。古代中国語の本文を保ったまま、読み・語順・活用語尾を示す注記を加える訓点である。この注記は本文の中には入らず、その傍らに書き添えられた。注記を本文の中に取り込んで一続きの文として書き直したものが書き下し文であり、これも漢字仮名交じり文の源流のひとつとなった。一方、注記を傍らに置いたまま残す方法は、漢字の読みを仮名で傍記する振り仮名へ、そして印刷におけるルビにつながった。ルビは、漢字仮名交じり文と根を同じくする兄弟であると言える。
傍らに書き添えるという形は、読みを示すことから離れた使い方も生んだ。漢字に、その読みではなく、書き手が選んだ別の語を重ねる。これを創作ルビと呼ぶ。（典拠〓）
（図：宣命書き。イメージ）

### 縦書きと横書き
歴史的に日本語は文を縦方向に書いたが、西洋の数字や単語の影響で横書きもなされるようになった。デジタルデバイスにおいては横書きが主流である。この文書は横組を前提として書き、縦組については〓で、横組と異なる点をまとめて扱う。


## 2.2 日本語デジタルテキストに使用する文字
> それぞれの文字に関する基礎知識。非日本語話者にとって以降の議論を理解するベースとなると共に、日本語話者にとっても興味深い基礎となることを期待する。ただし教科書でも学術書でもないのでさらっと簡潔に。

日本語デジタルテキストで使用する主な文字種について説明する。

### ひらがなとカタカナ
ひらがなとカタカナは仮名と総称され、日本語の発音を表す日本語独自の表音文字である。ひらがなとカタカナは一対一に対応しており、同じ音にひらがなとカタカナが一つずつある。現代日本語では、基本となる46文字（「ゐゑ」を含まない）。これらに発音を変える、ダイアクリティカルマークである濁点と半濁点のついた文字、「小書き」と呼ばれる基本の文字を小さくした文字や、長音符が組み合わさる。小書きの仮名は前の字に続くように、横書きではボディの左下に、縦書きではボディの右上に配置される。

> ここで小書きが発音を変える（拗音を作る）と言ってしまうと正確でない。「ゃゅょ」は拗音と呼ばれる新たな発音を作り、ダイアクリティカルマークに似た働きがあるが（そのような文字の名前はある？）、「っ」はそれ自身が促音で一つのモーラを形成する。ただし、そのような詳細は組版とほとんど関係がなく（行の折り返しの議論を除く）、離脱を招く危険性があるので含めるとしたらside note。

> 近年、長音を表すのに「〜」が使われることがあることに言及する

ひらがな、カタカナの両方とも、中国から来た漢字を日本語として消化する過程で漢字を簡略化する形で生まれ、漢字の意味を捨てて音だけが残ったものである。ひらがなとカタカナは両方とも日本語の発音に対応するため、基本的に一対一に対応するが、これらは生まれた過程と用途が異なる。ひらがなは日本語を素早く書き表すための筆記体から生まれ、カタカナは中国語を日本語として読むための付記のために漢字の形の一部を利用して生まれた。ひらがなは曲線が多く、カタカナに直線が多いのはこのためである。

先に触れたように現代日本語においてひらがなは、語と語をつなぐ助詞を表し、また語の活用語尾を表す。この役目のために、日本語はしばしば漢字とひらがなの繰り返しのリズムを作る。ひらがなはまた、内容語を示したり、読みの難しい漢字の読みを示すのにも用いられる。

カタカナは、音の表現に使われる。すなわち外来語の単語を音で表し〈transcribe〉、動植物名、またオノマトペ〈Onomatopoeia〉などに使われる。

##### 図：カタカナの用法の例
```
> 外来語（テキスト、ステーキ）、オノマトペ（ピチピチ、ジャブジャブ、ゴロゴロ）
```

読みにくくはあるが日本語を全てひらがな、もしくは全てカタカナで表すことができる。日本語を学び始めたばかりの子どもの教科書はすべてひらがなで、文節〈phrase〉ごとに分かち書きされている。子供達はまずひらがな、カタカナ、そして簡単な漢字の順に文字を学び始める。

### 漢字
漢字は中国で生まれた表意文字であり、それぞれの文字が一つもしくは複数の概念を表す。日本語において漢字は主に内容語〈content words〉を作る。

どのくらい細かい違いまで数えるかにもよるが、無数の漢字が存在する。漢字一つ一つが英単語やその語根、歴史上存在したスペリングバリエーションに対応するものと考えると、その多さを理解しやすいだろう。日本において日常的に用いられる漢字は2,000字あまりで、政府が「常用漢字」として定めている。子の名にはこれに加えて800字あまりが認められている。書籍を含め、現代日本語を十分に表すためには約1万字が必要であり、これが日本工業規格 JIS X 0213 の定める範囲である。

> 異体字について一言ほしい

既に述べたように多くの漢字には複数の読みがあり、これが日本語における表記と読みの二重構造を作っている。漢字の入力も、読みを入力して候補から選ぶ方式が一般的である。このため、読みの分からない字を入力する手段は限られている。

### アラビア数字と漢数字
歴史的には数字を漢字で示していた。現代では数量の表記にはアラビア数字を用いるのが一般的である。縦書きにおいては漢数字を使うことが多いが、最近ではアラビア数字にする例も増えている。

数が語の構成要素になっている場合、例えば固有名詞、慣用句や専門用語などの中に数字が現れる場合は漢字を使う。英語でも固有名詞や慣用表現の中では数を綴る。ただし英語では文頭や小さい数でも綴るなど、位置や大きさによる規則もあるのに対し、日本語の使い分けは語の構成要素かどうかによる。

##### 図：漢数字を使う例
```
四日市市（地名）、二酸化炭素（化合物名）、八十八夜（立春から88日目、茶摘みの頃）、七五三（子どもの成長を祝う行事）、一石二鳥（一つの行為で二つの利益）
英語の例：Thousand Oaks（地名）, the Ten Commandments（十戒）, my two cents（大した意見じゃないけど）
```

### ラテン文字
ラテン文字は、西欧語由来の単語や技術的な内容を表すために使用される。また、ブランド名、製品名や企業名などを中心に、外国由来でなくてもラテン文字を使用した単語が使われることがあり、また略語や記号としても広く利用されている。これらに見られるように、ラテン文字は現代日本語の一部として定着している。

ラテン文字とアラビア数字をまとめて英数字と呼ぶ。英数字は一般的に一文字一文字独自の幅を持つ。
> このパラグラフ、英数字、という言葉がこの文書でどのくらい重要か最後にレビューして決める。欧字、という言葉もあるので不要な可能性もある。

##### 図: ラテン文字で書かれる日本語の例
```
Tシャツ、Uターン、OK、AI（日常単語）、pH（学術用語）、SONY（企業名）、Suica（サービス名）、kg（単位）
```

### 約物と記号
**約物**という言葉が指す範囲は文脈により異なるが、この文書では、punctuation の訳語として、句読点、疑問符と感嘆符、引用符、括弧、ダッシュなど、文章の構造を示す文字を指す。前後の文字との字間の調節や行送りにおける分割の可否など、レイアウト上の規則を持つものが多い。
> 約物を狭く限定した。ここではしるし物は記号、長音符や繰り返し符号は文字として取り扱う。

**記号** はそれ自体が意味を持つ文字である。例えば数学記号、通貨記号、矢印、図形的なものなどがある。ただしUnicode によれば（場所を明記）、約物と記号の区別は絶対的なものではなく、% や & のように、どちらとも解釈できる文字がある。

約物には、和文用約物と欧文用約物がある。前者は仮名や漢字とともに、後者はラテン文字とともに使われる。和文用約物は欧文に起源を持つものが多く、見かけや用法の似ているものが多い。しかし同じように見えるものであっても、和文用約物は仮名や漢字に、欧文用約物はラテン文字に合わせたデザインになっているので、混用しない。この点は「文字の使い方」で詳しく述べる。

### 全角英数字、および半角カタカナ
#### 全角英数字
日本語の文字セットには、標準的なラテン文字やアラビア数字に加えて、和字と同じ幅で表示されるラテン文字とアラビア数字がある。これらを全角英字、全角数字、総称して全角英数字と呼ぶ。

例えば「Ａ」と「A」は、前者が全角英字、後者が通常のラテン文字であり、文字の意味は同じであるが、それぞれ異なる文字コードを持っている。使い方の注意は次節で述べる。

##### 注: 「半角」について
なお、全角英数字と対比して、通常のラテン文字、アラビア数字を表す言葉として「半角英字」「半角数字」「半角文字」などの言葉が使われることがある。初期のコンピューターではラテン文字やアラビア数字は和字の半分の固定幅を持っていたが、現代のデジタルデバイスにおいて英数字は一般的に文字ごとに幅を持っており、「半角」はもはや技術的に間違った用語である。この文書では全角英数字を指す場合には全角英数字と明確に示し、単にラテン文字、アラビア数字などと書く場合には標準的なラテン文字、アラビア数字を指すこととする。

#### 半角カタカナ
初期のコンピューターではターミナル画面上に一般的に縦横2:1の固定の大きさにアルファベットを表示するようになっていた。これら初期のコンピューター上で日本語を表示するために作られた文字が半角カタカナであり、現在では歴史的な互換性のために存在している。

可読性に劣り、また他の文字との視覚的一貫性にも問題があるため、半角カタカナの使用は避けるべきである。

## 全角英数字の使用
全角英数字には利点と欠点がある。

##### 利点
- フォントを指定できない環境でも、周囲の和字とスタイルが揃う。国際化環境では通常のラテン文字やアラビア数字が和文とは別のフォントから表示されることが多いが、全角英数字はその影響を受けない。
- 縦書きで、指定なしに正立する。このため、「Tシャツ」など英字が単語の一部として1,2文字が使われる場合などに簡便である。

##### 欠点
- 通常のラテン文字やアラビア数字と混ぜると、同じ文字が幅違いで並ぶことになり、見た目が揃わない。国際化環境では、英数字に和字とは異なるフォントが用いられることが多く、この場合は文字デザインも揃わなくなる。
- 英単語や英文に用いると可読性に劣る。また、行の折り返しが単語の途中で起きる。
- 1, 2字ではなく、続けて用いる場合には全角英数字は幅が広すぎ、文字列が長くなるほか、括弧や句読点との間や行頭に不要な空間が生じる。
- アクセント符号の付いた文字が存在しないため、それを必要とする語には使えない。
- URLの機能的な部分には使えない。ここには通常の英数字を用いることが規定されており、全角英数字を使うとURLとして動作しない。HTML／CSS／Markdown などの機能的な部分についても同様である。

上記を考慮すると、通常のラテン文字を使用することをデフォルトとし、全角英字を使用するのは、単語の一部などに限定的に1,2文字を使用する場合に限定するのが合理的であろう。また、通常のラテン文字と混在させると幅やデザインの違いが目立つため、両方が現れるテキストでは通常のラテン文字に統一するのがよい。数字については、ラテン文字のような記号的な使用の慣用がないため、横書きでは常に通常のアラビア数字を用いる。

縦書きで正立させることが目的の場合は、正立を体裁で指定できる環境では、通常のラテン文字やアラビア数字を用いてそちらで指定し、それができない環境では代替手段として全角英数字を用いる。〔正立の指定方法は〓章〕

### 文字で見た目を整えない
原則として、見た目を整えるのは、空白文字や改行文字ではなく体裁の指定で行うべきである。空白文字や改行文字を用いて見た目を整える方法は簡便で使いやすいが、本来望ましい方法ではない。これは、文字は内容を表すものだからである。体裁の整形のために文字を使うことの一番の問題点は、それがコンピューターにとっての文字内容を変えてしまうことである。冒頭に書いたように、デジタルテキストは生きたデータであり、選択、検索、切り貼り、異なるスタイルの適用といった操作の対象となる。

例えば、整形のために日本語の単語の途中で改行した場合、その単語はもはや検索できず、また読み上げることができない。段落先頭の一字下げに全角空白を使うと、例えば段落のスタイルを変更したい場合に、テキストがそれに柔軟に対応できなくなる。しかし、段落の体裁をサポートしないアプリケーションや、段落の体裁をサポートしても、全幅を単位とする字下げの指定をすることのできないアプリケーションの場合には、代替え手段として全角空白を用いる。

# 3 日本語のフォント
ここで書体とは文字デザインのカテゴリを指し、フォントとは名前のついた具体的な実装を指す。

> 逆に、国際的な文字環境の下では、文字コードは正しいのに見えているものが正しくない、という現象も起こる。これはフォントが適切なものでない場合に起こり、漢字や約物の字形が意図しない形になることがある。

## 日本語フォントの概要
先に述べたように日本語は複数の起源を持った文字を使用するので、一つの日本語フォントにはそれら複数の種類の文字が入っている。

##### 日本語フォントの構成
（図：日本語フォントの構成。和字（漢字、仮名、和字の約物）、欧字（ラテン文字、ラテン文字の約物）、記号など）

標準的な日本語フォントでは、和字部分は統一した大きさの四辺形の枠の中にデザインされている。ほとんどの場合和字の枠は正方形であり、縦書き、横書き両方に使いやすい。この正方形を全角と呼ぶ。この枠が正方形でなく、縦長、または横長のもの、またそれ以外の形式のものもある（side note参照）。

和字は、この四辺形の枠いっぱいに描かれるのではなく、枠よりやや小さくデザインされる。隣り合う文字の間に見える空きは、枠と文字の間の余白によって作られている。和字は、この枠を隙間なく並べて配置した状態で読みやすくなるようにデザインされている。

枠に対して文字をどれだけ大きく描くかはフォントによって異なり、本文用のフォントでは比較的小さく、見出し用のフォントでは比較的大きい。このため、同じ文字サイズを指定しても、フォントによって文字の見た目の大きさは異なる。

（図：ボディと字面。大きいもの、小さいもの）

（字面率の違いの理由は、1. 見出しは一体として見せたい 2.大きめのサイズで使われるが、その場合、空白部分が視覚的により大きく見える。これはどこか別のところに書く）

この四辺形の枠が実際にどれだけの大きさで表示されるかを決めるのが、文字サイズの指定である。表示された四辺形の縦の寸法が、文字サイズとなる。（枠自体は表示されない。より良い言い方はあるか？）

等幅フォントを除いて、欧字はプロポーショナルである。

#### ボディ、全角と全幅、文字サイズ
和字が納まる四辺形をボディと呼ぶ。ボディは抽象的な枠であり、それ自体は寸法を持たない。これが実際にどれだけの大きさで表示されるかを決めるのが、文字サイズの指定である。表示されたボディの高さが、文字サイズとなる。

多くの日本語フォントでボディは正方形である。この場合、幅と高さが等しいため、文字サイズがそのまま幅にもなる。この幅を持つ文字を全角と呼ぶ。

ボディが正方形でないフォントでは、幅と高さが異なる。この場合、文字サイズはボディの高さを表し、幅とは一致しない。このような文字を全角と呼ぶことはできない。しかし組版の規則は文字を並べる方向の幅を基礎とするため、これを表す語が必要になる。そこで、この幅を「全幅」と呼ぶ。

##### site note: 標準的でない字幅を持つフォント
```
多くの日本語フォントは、和字がすべて同じ全幅を持ち、英数字は文字ごとの幅を持つ。これに当てはまらないものがある。固定幅の多い割合の順に並べると：
英数字が固定幅であり、全幅のちょうど半分の幅を持つもの：日本語の等幅フォントがこの形式である。
和字がすべて同じ全幅を持ち、英数字がプロポーショナルなもの：これが標準的な構成で、ほとんどの日本語フォントがこの形である。
仮名と漢字がそれぞれ別の固定幅を持つもの：仮名を漢字より狭くデザインしたもので、AXISフォントのコンデンス系などがそれである。
仮名がプロポーショナルなもの：仮名が字ごとに異なる幅を持つ。MS P明朝などがこの例である。
和字全体がプロポーショナルなもの。 漢字も含めて字ごとにそれを囲む四辺形の大きさが異なる。「かづらぎ」がこの例である。
```

##### 仮名のバリエーション
現代日本語の文章では、仮名の占める割合が漢字を大きく上回る。よって仮名のデザインを変えることで効果的にテキストの用途や見かけを変えることができる。このため、活字の時代から、同じ書体に複数の仮名バリエーションを用意することが行われてきた。

仮名のバリエーションには、字面の小さいもの（小がな）、大きいもの（大がな）、古い時代の様式を再現したものなどがある。仮名の字面の小さいものは、一般的にクラシックな雰囲気を持ち長文を読ませる書籍（小説やエッセイなど）の本文に向く。また、字面の大きいものは、一般的にモダンな印象を持ち、文字列としての一体感や文字単位での視認性に優れている。

（図：仮名のみが異なる二つのフォントの例。游明朝体 vs 游明朝体36ポかな、小がな大がなの例も）

##### 日本語フォント中の英数字のデザイン
日本語フォントの英数字は和字と使われることを念頭にデザインされている。特にラテン文字はディセントを浅く、重心が仮名や漢字と合うようにデザインしてあることが多い。

ただし国際化環境では、テキストに単独のフォントではなくフォントのリストを適用することによって、単独のフォントが表示できる文字範囲の制限を取り除いていることが多い。このような場合、ラテン文字は和文フォントとは別個のラテン文字用フォントから表示されることが多く、和字と使われることを念頭にデザインされたラテン文字は使われない。また、アプリケーションによっては英字や和字など特定の文字範囲に対して別々のフォントを指定できるようになっているものもある。

## 日本語書体の種類
### 汎用の書体
汎用の書体には、明朝体、ゴシック体、丸ゴシック体がある。

明朝体は、縦画が太く横画が細く、横画の右端に「うろこ」と呼ばれる三角形の飾りを持つ。ストロークの太さに差があり飾りを持つという点で、欧文のローマン体に近い印象を与える。ゴシック体は、縦画と横画の太さがほぼ等しく、飾りは軽微である。欧文のサンセリフ体に近い。丸ゴシック体は、ゴシック体の画の端を丸めたもので、欧文のラウンド系の書体に近い。

これらは様々な内容のテキストに汎用に使える。特別な効果を狙っているのでない限りこれらの書体を使用するべきであろう。汎用のフォントとして、多くの選択肢があり、文字数の揃っているものが多い。英字と組み合わせやすいのもこれらの書体である。国際化にはこれらの書体を使うべきである。

（図：明朝体、ゴシック体、丸ゴシック体の比較。同じ文字列で）

##### side note: 明朝体とローマン体
明朝体とローマン体の対応には由来がある。19世紀に西洋の宣教師が漢字の金属活字を作る際、既存の書体の中から明朝体が選ばれた。欧文の印刷で用いられていたローマン体と調和するためだったとされる。日本語の明朝体は、この選択を受け継いでいる。

### 特別な用途の書体
ペンや鉛筆で書いたような書体や教科書体は、カジュアルなもしくは懐かしい雰囲気を持ち、横書きへの適応性があり、比較的応用範囲が広い。

（図：ペンや鉛筆で書いたような書体や教科書体の例）

筆書きの雰囲気の強く残っている書体は一般的に特定のコンテキストを強く想起させ、英字との適合性が低いので、その効果が意図的でない限り、それぞれに合ったコンテキストで、和字に限定して用いるのが安全である。

中国からきた伝統書体：楷書、行書、草書、篆書などは、縦書きで用いられてきた書体であり、縦書きに用いる。特に行書と草書、及び楷書の仮名は、文字を縦に連ねて書くことを前提としており、字形にその運びが残っている。

これらは公的な、権威的な、または伝統的、古風な雰囲気を持つ。

（中国からきた伝統書体の例）

日本の江戸文字は歌舞伎や相撲、落語の興行など特定のコンテキストでのみ使われる文字であり、文字だけでそれらのコンテキストを想起させる。よってそれぞれのコンテキストを外れて使う場合には明確な意図と注意が必要である。

（江戸文字の例）

特殊な用途の書体に、多くの漫画で使われるアンチック、明朝体でありながら手書きの形を模した学参書体、映画の字幕に使われる字幕用書体などがある。

（これらの書体の例。コンテキストの中で）

### 日本語には日本語用フォントを明示的に使う
漢字の形は、同じ文字コードであっても、日本、中国、台湾など、それぞれの漢字使用地域で相互に異なる。多くの場合読めはするが、その地域向けでない字形が混ざると、違和感のある、プロフェッショナルでない仕上がりとなる。

（図：同じ文字列を日本語フォント、中国語フォント、韓国語フォントで表示した比較。日本語として正しい字形と、そうでない字形。糸偏など特徴的な違いを持つもの）

また、日本語用でないフォントでも仮名を含んでいるものがあるが、デザインがプロフェッショナルな品質ではなく、またウェイトやサイズの漢字に対するバランスが悪いものもあるので注意する。句読点の位置が異なるなどの問題がある。

（図：このサイト、からのスクリーンショット、ブランドがわからないように: https://press.jp.porsche.com/prod/presse\_pag/PressResources.nsf/Content?ReadForm&languageversionid=1634483&view=1）

**HTMLでは**、lang="ja"のようにlang属性で言語を示したうえで、CSSのfont-familyで日本語用のフォントを指定する。lang属性は、フォントが指定されていない場合に適切なフォントが選ばれるためにも必要であり、また読み上げなどにも用いられるので正しく設定することが重要である。多言語のサイトでスタイルを共通にしている場合は、:lang()セレクタを使い、言語ごとにフォントのリストを書き分ける。side note参照のこと。

**アプリケーションなどでフォントを指定できる場合**は、日本語用のフォントを明示的に指定する。

**フォントを指定できない場合**は、フォントが何らかの仕組みで自動的に選ばれている。システムやアプリケーションの言語設定によって決まっている場合もあり、その場合、システム全体やアプリケーションの言語設定を日本語にする。

```

### 英字書体との合わせ方
（山本さんがきた時に議論）

書体、サイズとウェイトの合わせ方。

日本語コンテキストであって特に意図のない場合は、日本語フォントに含まれる英字を使うのが賢明である。そのフォントの和字と使われることを念頭に、上下位置、サイズ、ウェイト、などを揃えてデザインされているからである。例えば和文書体に含まれる英字は和文との相性が良いように、特に下へのはみ出し（ディセンダ）が小さくデザインされている。

英字が重要な用途において、または国際化環境などでは、英字に対して和字を合わせる必要のある場合がある。この場合の注意点を


デザイン：不安なく合わせられるのは、Serifと明朝、Sans-serifとゴシック、Roundと丸ゴシック。他の場合は書体の知識のある人の判断が必要。例えば、筆書系書体が伝統的だからといって、伝統的な英字書体と合うわけでも、また用途が似ているわけでもないのに注意（e.g. 英語筆記体で書いてあるバースデーカードを日本語化する際に行書が最適というわけではない）。またディスプレー書体を含んだテンプレートなどの国際化に注意。例えば、特定の国のスクール風はその他の国のスクール風ではない。

サイズ：従属欧文はディセンダが小さく日本語書体に合わせやすくなっている。任意の欧文と合わせるときのサイズの合わせ方。フォントサイズでは必ずしも合わせられない（サイドノートでcssのプロパティの紹介）。

ウェイト：
